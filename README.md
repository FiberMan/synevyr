# Автоматизація — ОК «Синевир»

Система автоматизації для обслуговуючого кооперативу «Синевир»: управління чергою на отримання ключів, реєстр рішень з голосуванням та email-сповіщення для правління.

Побудовано на **Google Apps Script** з інтеграцією Google Calendar, Google Sheets та Google Forms.

---

## Структура проекту

| Файл | Призначення |
|---|---|
| `autoCancelBadBookings.js` | Основний скрипт: валідація записів, черга, синхронізація реєстру |
| `notifyBoardOnNewProposal.js` | Сповіщення правління про нові пропозиції з форми |

## autoCancelBadBookings.js

Скрипт прив'язаний до **публічної таблиці** кооперативу (аркуш «Учасники кооперативу»).

### Функції

#### `autoCancelBadBookings()`

Перевіряє записи в Google Calendar на найближчі 90 днів і автоматично:

1. **Парсить події** — знаходить номер квартири в описі події (поле «№ квартири»)
2. **Видаляє невалідні** — скасовує записи з неправильним номером квартири
3. **Видаляє дублікати** — якщо на одну квартиру є кілька записів, залишає лише найпізніший
4. **Перевіряє борг** — скасовує запис, якщо у квартири є заборгованість (стовпчик Q)
5. **Зберігає контакти** — витягує ім'я, телефон та email з опису події і записує в таблицю
6. **Надсилає email** — повідомляє про скасування з вказанням причини
7. **Формує чергу** — записує підтверджені бронювання в аркуш «Черга»

**Тригер:** за часом (наприклад, щогодини або щоденно).

#### `writeQueue(confirmedBookings)`

Записує підтверджені бронювання у вкладку «Черга» в хронологічному порядку. Стовпці: дата запису, № квартири, ім'я, телефон, email, дата оновлення.

#### `syncRegistryToPublic()`

Синхронізує виконані рішення з **зовнішньої таблиці** Реєстру рішень до стовпчика «Прийняті рішення» (AA) у публічній таблиці:

- Читає рішення зі статусом «Виконано»
- Парсить номери квартир (підтримує діапазони: `1-5, 8, 10-12`)
- Створює клікабельні гіперпосилання (RichText) на відповідний рядок Реєстру

**Тригер:** за часом (наприклад, щоденно).

#### Допоміжні функції

| Функція | Опис |
|---|---|
| `parseContactInfo(description)` | Парсить ім'я, email, телефон із HTML-опису події |
| `parseAptList(raw)` | Парсить рядок квартир: `"1, 3-5, 8"` → `[1, 3, 4, 5, 8]` |
| `sendCancellationEmail(event, flatNumber, reason)` | Надсилає HTML-лист про скасування запису |
| `formatDateTime(date)` / `formatDate(date)` | Форматування дати з урахуванням часової зони |
| `escapeRegex(value)` | Екранування спецсимволів для RegExp |
| `getGuestEmail(event)` | Отримує email першого гостя календарної події |

## notifyBoardOnNewProposal.js

Скрипт прив'язаний до **таблиці Реєстру рішень** (де прикріплена Google Form).

### Функції

#### `notifyBoardOnNewProposal(e)`

Обробник нової відповіді форми. При надходженні пропозиції:

1. Зчитує дані з нового рядка форми (автор, квартири, опис, файли)
2. Формує HTML-лист з таблицею деталей та кнопкою «Перейти до голосування»
3. Надсилає email усім членам правління

**Тригер:** `onFormSubmit` (встановити вручну в Apps Script).

#### `getBoardEmails(ss)`

Збирає email-адреси з аркуша «Члени правління».

#### `escapeHtml(text)`

Екранує HTML-символи та замінює `\n` на `<br>` для коректного відображення тексту в email.

### Конфігурація (REGISTRY_CONFIG)

```javascript
const REGISTRY_CONFIG = {
  votingSheetName: "Голосування",

  formAuthorCol: 2,     // B — Email автора
  formAptsCol: 3,       // C — Квартири
  formDescCol: 4,       // D — Опис
  formFilesCol: 5       // E — Файли
};
```

## Налаштування тригерів

### autoCancelBadBookings

1. Відкрийте публічну таблицю → Extensions → Apps Script
2. Вставте код з `autoCancelBadBookings.js`
3. Triggers → Add Trigger:
   - Function: `autoCancelBadBookings`
   - Event source: Time-driven
   - Type: Hour timer / Day timer

4. Додатково для синхронізації реєстру:
   - Function: `syncRegistryToPublic`
   - Event source: Time-driven
   - Type: Day timer

### notifyBoardOnNewProposal

1. Відкрийте таблицю Реєстру рішень → Extensions → Apps Script
2. Вставте код з `notifyBoardOnNewProposal.js`
3. Triggers → Add Trigger:
   - Function: `notifyBoardOnNewProposal`
   - Event source: From spreadsheet
   - Event type: On form submit

### Авторизація

При першому запуску Google покаже попередження:

1. Натисніть **«Додатково»** (Advanced)
2. Натисніть **«Перейти до [назва проекту] (небезпечно)»**
3. Натисніть **«Дозволити»** (Allow)
